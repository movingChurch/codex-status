# Preview image

`hud-preview.png` shows the real `src/renderer.py` output in a terminal emulator, with the synthetic values in `demo-snapshot.json`. The image includes a decorative window frame; it is not a screenshot of a live Codex account or a running model task. The HUD labels and colors come from the shipped renderer.

Bars mean used capacity; numbers mean remaining capacity. The fixed clock keeps the observation age reproducible. The browser capture checked all three terminal lines against the renderer output before saving the image.
